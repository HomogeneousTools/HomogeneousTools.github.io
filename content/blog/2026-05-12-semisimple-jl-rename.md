The Julia package previously known as `Lie.jl` has been renamed to
[Semisimple.jl](https://github.com/HomogeneousTools/Semisimple.jl).
This was needed,
because the Julia registry rejected the name `Lie.jl` as being too short.
I doubt many people have started using the package,
I just have some renaming to do in the (not yet public) downstream packages.

The package should within the next 3 days be part of the Julia registry,
so that you can install it in the usual way for Julia packages.
Stay tuned for an update on that!
